How these were built

  • No frameworks, no build step. Plain HTML, CSS, and JavaScript that loads fast and runs on any static host.
  • Brand kit first. Exact brand colors, the specified typefaces, and the supplied logos on every page.
  • Accessible by default. Keyboard focus on every control, labeled forms, color contrast checked, reduced motion respected.
  • Mobile tested. Every page checked at phone width with no sideways scrolling.

Clearline, BoxBolt, and Concrete Culture are fictional brands created for demonstration. Forms and checkouts are demos and send nothing.
