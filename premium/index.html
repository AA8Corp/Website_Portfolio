Under the hood

Framework
React 19 with TypeScript, React Router
3D
Three.js through React Three Fiber and Drei, all models built in code
Motion
Framer Motion for page transitions, scroll-linked scenes, and layout animation
State
Zustand, persisted to the browser for quotes and the shopping bag
Build
Vite multi-page build, self-hosted fonts, deployed as static files
